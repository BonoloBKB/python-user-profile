# Python User Profile

A beginner Python project created while learning how to work with strings, user input, and basic data types.

## What the program does

The program asks the user for:

- First name
- Surname
- Age
- Favourite number
- Bio message

It then displays the information in different formats.

## Concepts I practiced

- `input()`
- Variables
- Strings
- f-strings
- `.strip()`
- `.title()`
- `.upper()`
- `.lower()`
- `.replace()`
- `len()`
- `type()`

## What I learned

This project helped me understand how to collect information from users and manipulate strings in Python.
